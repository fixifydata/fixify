# Fixify service content research

The expanded Fixify service catalog was informed by the public Datahash implementation service taxonomy and selected detail pages. Fixify wording, organization, and visual treatment remain original.

- Implementation catalog: https://www.datahash.com/services/implementations/
  - Themes reviewed: web/server-side signals, app and attribution, analytics and data, consent, automation, experimentation, catalog/feed work, and a discover-to-handover delivery model.
- GA4 detail: https://www.datahash.com/services/implementations/web-analytics-ga4/
  - Themes reviewed: event taxonomy, enhanced ecommerce, CRM/Ads/BI integrations, reconciliation, governance, validation and handover.
- Web CAPI detail: https://www.datahash.com/services/implementations/web-capi/
  - Themes reviewed: server-side architecture, event IDs, deduplication, hashing, enrichment, platform delivery, diagnostics and match quality.
- Consent detail: https://www.datahash.com/services/implementations/consent/
  - Themes reviewed: CMP integration, consent states, Consent Mode v2, region-aware defaults, validation and documentation.
- BI and data integration detail: https://www.datahash.com/services/implementations/bi-data-integration/
  - Themes reviewed: dashboards, warehouse models, ad/analytics/CRM/offline data integration, anomaly alerts, metric validation and data freshness.

The catalog also follows platform implementation themes from Google’s public Tag Platform documentation, especially consent-aware server-side measurement: https://developers.google.com/tag-platform/tag-manager/server-side/consent-mode and https://developers.google.com/tag-platform/security/guides/consent.
